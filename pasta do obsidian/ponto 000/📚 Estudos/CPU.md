# 🖥️ CPU — Processador

> *"O cérebro do computador: quem executa todas as instruções."*

**Categoria:** [[ESTUDOS E CURSOS - Meu aprendizado]] · Ligado a [[METAS DE EQUIPAMENTOS]]

---

## 🎯 O que é

A **CPU** (*Central Processing Unit* / Unidade Central de Processamento) é o componente que executa as instruções dos programas — cálculos, lógica e controle. Para quem edita **foto e vídeo**, é uma das peças que mais influencia a velocidade do trabalho.

---

## 🔩 Como se avalia uma CPU

| Especificação | O que significa | Por que importa na edição |
|---------------|-----------------|---------------------------|
| **Núcleos (cores)** | "Cérebros" paralelos | Mais núcleos = exportar/renderizar mais rápido |
| **Threads** | Tarefas simultâneas por núcleo | Ajuda no multitarefa (ex.: Lightroom + navegador) |
| **Clock (GHz)** | Velocidade de cada núcleo | Importa para resposta em tempo real |
| **Cache** | Memória ultrarrápida interna | Reduz gargalos em tarefas repetitivas |
| **TDP (watts)** | Consumo/calor | Define refrigeração e fonte necessárias |

---

## 🏭 Os dois fabricantes principais

| | **Intel** | **AMD** |
|---|-----------|---------|
| Linha desktop | Core (i3, i5, i7, i9) | Ryzen (3, 5, 7, 9) |
| Ponto forte | Clock alto por núcleo | Muitos núcleos por preço |
| Uso típico | Jogos, resposta rápida | Renderização, multitarefa |

> Ambas servem bem para edição. A escolha depende de **orçamento** e do **software** que você mais usa.

---

## 🎬 CPU vs GPU na edição

- **CPU** → Lightroom, revelação RAW, exportação, lógica geral
- **GPU (placa de vídeo)** → efeitos, timeline de vídeo, aceleração no Premiere/DaVinci

> Para foto: priorize CPU + RAM. Para vídeo: CPU **e** GPU boas, com bastante RAM (16 GB mínimo, 32 GB ideal).

---

## 🛒 Referência para montar um PC de edição

1. **CPU** — Ryzen 5/7 ou Core i5/i7 de geração recente
2. **RAM** — 16 GB (mín.) a 32 GB
3. **SSD NVMe** — sistema + cache de edição (velocidade)
4. **GPU** — dedicada se for editar vídeo
5. **Fonte + refrigeração** — compatíveis com o TDP da CPU
