# 💵 Precificação de Ensaios

> Preço não é chute: é custo + tempo + valor percebido.

---

## 🧮 Fórmula base

```
Preço = (Custo fixo/hora × horas totais) + custos do trabalho + margem de lucro
```

**Horas totais = captação + edição + deslocamento + comunicação** (um ensaio de 1h costuma consumir 4-6h reais).

| Componente | Como calcular |
|-----------|---------------|
| Custo fixo/hora | Despesas mensais ÷ horas trabalháveis → [[gastos mensais fixos]] |
| Custos do trabalho | Transporte, alimentação, impressões, desgaste de equipamento |
| Margem | 30-50% sobre o total (é o que vira lucro e reinvestimento) |

> Fotos de produto têm sinergia direta com a [[LOJA VRGS - E-commerce de roupas]] — o que eu cobraria de cliente é o que economizo fazendo o catálogo próprio.

---

## 🧠 Princípios

1. **Nunca competir por preço baixo** — competir por estilo e confiança → [[01 - Personal Branding]]
2. **Sinal de 30-50%** para reservar a data → [[CONTRATO MODELO - Ensaios]]
3. Preço público = preço cheio; desconto é exceção negociada, não regra.
4. Reajustar quando a agenda lotar: agenda cheia = preço baixo demais.
5. Pacotes (3 ensaios/ano) fidelizam → recorrência.
