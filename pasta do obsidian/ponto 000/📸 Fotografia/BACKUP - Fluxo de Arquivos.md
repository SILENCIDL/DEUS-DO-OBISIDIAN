# 💾 Backup — Fluxo de Arquivos

> "ORGANIZAÇÃO DO HD" era a primeira pendência urgente da [[ORGANIZAÇÕA URGÊNCIA]] — esta nota resolve isso de vez.

---

## 🛡️ Regra 3-2-1

```
3 cópias de cada arquivo importante
2 mídias diferentes (HD + nuvem)
1 cópia fora de casa (nuvem)
```

| Cópia | Onde | Status |
|-------|------|--------|
| 1ª — Trabalho | HD do computador | ✅ |
| 2ª — Backup local | HD externo | ⬜ Organizar |
| 3ª — Backup remoto | Nuvem (Google Drive/Mega/Backblaze) | ⬜ Escolher serviço |

---

## 📁 Estrutura de pastas padrão

```
FOTOGRAFIA/
├── 2026/
│   ├── 2026-06-15 - Ensaio [Cliente]/
│   │   ├── 01_RAW/          (originais, nunca mexer)
│   │   ├── 02_Selecionadas/ (escolhidas para edição)
│   │   ├── 03_Editadas/     (finais em alta)
│   │   └── 04_Entrega/      (redimensionadas/web)
│   └── ...
├── PESSOAL/      (projetos autorais → [[PROJETO OLHAR]], [[PROJETOS CINEMATIC]])
└── PORTFOLIO/    (melhores de todos os tempos → [[PORTFÓLIO - Curadoria 2026]])
```

**Nomenclatura:** `AAAA-MM-DD - Tipo - Cliente` (ordena sozinho por data).

---

## 🔁 Rotina

### Após cada ensaio (no mesmo dia!)
- [ ] Descarregar cartão → pasta `01_RAW`
- [ ] Copiar RAW para o HD externo
- [ ] Só formatar o cartão depois das 2 cópias

### Mensal
- [ ] Subir pastas `03_Editadas` para a nuvem
- [ ] Limpar arquivos temporários e exports duplicados

### Semestral
- [ ] RAW de trabalhos entregues há +6 meses → só HD externo (libera espaço)
- [ ] Verificar saúde do HD externo
