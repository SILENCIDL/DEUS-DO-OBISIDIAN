## 🔁 Fluxo padrão de atendimento

```
1. Contato inicial (DM/WhatsApp) → responder em até 2h
2. Enviar tabela de preços → [[PRECIFICAÇÃO DE ENSAIOS]]
3. Fechar data + contrato + sinal de 30-50% → [[CONTRATO MODELO - Ensaios]]
4. Ensaio → backup imediato dos arquivos → [[BACKUP - Fluxo de Arquivos]]
5. Edição (prazo combinado: ___ dias)
6. Entrega (galeria online / pendrive)
7. Pós-venda: pedir avaliação + autorização para portfólio
```

---

## 🔄 Reativação de clientes

A cada 6 meses, revisar clientes antigos:
- [ ] Aniversários → oferecer ensaio comemorativo (ver [[ANIVERSÁRIOS]])
- [ ] Famílias → ensaio anual
- [ ] Empresas/lojas → fotos de produto novas

> Cliente recorrente custa zero em captação. 3 clientes fiéis > 10 avulsos.
