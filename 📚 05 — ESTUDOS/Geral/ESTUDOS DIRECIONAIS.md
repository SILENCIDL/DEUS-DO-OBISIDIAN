# Estudos Direcionais

> Estudar sem direção é acumular informação. Estudar com direção é construir capacidade.

---

## O que são estudos direcionais

Estudos direcionais são aprendizados com propósito definido:
- Aprender algo específico para resolver um problema real
- Estudar a concorrência para melhorar o próprio trabalho
- Absorver linguagem do mercado para se comunicar melhor

Contraste com estudo amplo (faculdade, leitura livre):
- **Direcional**: aprendo X porque preciso fazer Y
- **Amplo**: aprendo X porque enriquece minha formação

## Método de estudo direcional

```
1. Identificar o problema / objetivo
2. Pesquisar 1-2 fontes específicas (não variar demais)
3. Praticar imediatamente o que aprendeu
4. Documentar no vault (este Obsidian)
5. Revisar em 7 e 30 dias (repetição espaçada)
```
