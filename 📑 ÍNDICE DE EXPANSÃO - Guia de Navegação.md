  - 💕 Planejamento Casal (viagens, finanças, projetos lar, growth)

### Especialização 1: Horta Autônoma
- **Hardware**
  - Arduino vs Raspberry Pi (controller)
  - Sensores umidade, temperatura (DHT22)
  - Válvula solenóide, bomba, luzes (opcional)
  - Energia: plug AC vs solar
  
- **Software**
  - Firmware Arduino (lógica threshold-based)
  - Conectividade: Obsidian API local, Cloud service, custom server
  - App: Telegram bot (MVP), dashboard web, mobile app
  
- **Agronomia**
  - Culturas iniciais (tomate, alface, ervas)
  - Sazonalidade Mantiqueira (primavera/verão/outono/inverno)
  - Compostagem (ciclo fechado, zero waste)
  
- **Escalabilidade**
  - Fase 2: múltiplas camas, pH sensor, fertilizante automático
  - Integração Home Assistant
  - ROI: ~2 anos payback ($300-500 inicial)

### Especialização 2: Planejamento Casal
- **4 Dimensões**
  - 🌍 Viagens (bucket list por estação, pesquisa, planning)
  - 💰 Finanças (budget categories, metas, transparência)
  - 🏠 Projetos Lar (pequenas melhorias, reformas, priorização)
  - 📚 Desenvolvimento Pessoal (seus goals, dela, juntos)
  
- **Ritmo & Cadência**
  - Semanal: 15min overview
  - Mensal: 1hr money date + projects review
  - Trimestral: 2-3hrs deep review + goals adjustment
  
- **Ferramentas**
  - Google Calendar (shared), Google Sheets (budget)
  - Notion (projects), Pinterest (ideias visuais)
  
- **Valores**
  - Partnership (decisões consenso)
  - Transparência (sem segredos financeiros)
  - Diversão (aventura regularmente)
