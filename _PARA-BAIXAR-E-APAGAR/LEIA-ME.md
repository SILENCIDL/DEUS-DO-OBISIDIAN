# ⚠️ PARA BAIXAR E APAGAR

Esta pasta existe **temporariamente** e contém o arquivo `senhas perfis.md`,
que foi retirado do vault do Obsidian por segurança (senhas em texto puro
não devem ficar em repositório Git).

## O que fazer quando estiver no computador

1. **Baixe** o arquivo `senhas perfis.md` desta pasta.
2. **Mova as senhas** para um gerenciador de senhas (Bitwarden é gratuito,
   ou o gerenciador do próprio navegador/celular).
3. **Apague esta pasta inteira** do repositório e faça commit.
4. **Recomendado:** troque as senhas que ficaram expostas aqui, pois elas
   permanecem no **histórico antigo** do Git mesmo depois de apagar o
   arquivo. Para limpar o histórico de verdade é preciso reescrevê-lo
   (posso fazer isso quando você pedir — afeta a branch `main` e exige
   force push).

## Por que não foi apagado de vez

Para você não perder o conteúdo: este ambiente é temporário, então o único
lugar garantido para o arquivo continuar acessível até você baixá-lo é o
próprio repositório — por isso ele está aqui, isolado e sinalizado, fora
da pasta do vault.
