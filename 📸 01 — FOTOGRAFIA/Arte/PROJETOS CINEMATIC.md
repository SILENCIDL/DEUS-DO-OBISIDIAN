# Projetos Cinematic

> Fotografia cinematic = fotografia que conta uma história. Cada foto é um frame de um filme que existe na sua cabeça.

---

## O que é um projeto cinematic

Série fotográfica com linguagem cinematográfica:
- Paleta de cores coesa (como um filme)
- Narrativa visual (começo, meio, clímax)
- Composição intencional
- Atmosfera emocional que o espectador sente

## Elementos de um bom projeto cinematic

### Antes de fotografar
- Qual é a emoção central?
- Qual é a paleta de cores?
- Qual é o fio narrativo?
- Quem/o quê é o protagonista?

### Execução técnica
| Elemento | Como aplicar |
|---------|-------------|
| Proporção cinemascope | Crop horizontal 2.39:1 |
| Profundidade | f/1.4-2.8 para bokeh forte |
| Cor | Flat profile + grading no Lightroom |
| Luz | Hora dourada, contra-luz, silhueta |
| Composição | Frames dentro de frames, simetria |

### Pós-produção
- Grade de cor coesa em todas as fotos
- Exportar como série numerada
- Apresentar com título + texto reflexivo

## Paletas cinematic inspiradoras

| Estilo | Cores | Referência |
|--------|-------|-----------|
| Noir urbano | Cinza, azul escuro, preto | Drive (filme) |
| Nostalgia quente | Laranja, âmbar, bege | Era analógica |
| Frio minimalista | Azul, branco, cinza frio | Fotografia escandinava |
| Natureza viva | Verde, terra, luz solar | National Geographic |
