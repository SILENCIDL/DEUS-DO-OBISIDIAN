# Metas de Equipamentos

> Equipamento bom não faz fotógrafo bom — mas o equipamento certo para o trabalho certo faz toda a diferença.

---

## Áreas de investimento

### Fotografia
- Flash externo (eventos, estúdio)
- Lente macro 105mm (produto + retrato premium)
- Tripé robusto

### Vídeo
- Gimbal para Reels e YouTube
- Microfone shotgun ou lapela
- Câmera com bom 4K (futuro)

### Áudio
- Microfone para YouTube (Blue Yeti, Rode NT-USB)

### CPU / Edição
- Monitor calibrado (precisão de cor)
- HD externo 4TB+ (backup)

---

## Roadmap de aquisição

### Curto prazo (3 meses)
- [ ] Flash externo Godox TT685
- [ ] HD externo backup (Western Digital 2TB)
- [ ] Tripé de alumínio 150cm+

### Médio prazo (3-12 meses)
- [ ] Gimbal (Zhiyun Crane M3 ou DJI RS2)
- [ ] Microfone externo (Rode VideoMicro)
- [ ] Lente 85mm ou 105mm macro

### Longo prazo (1-2 anos)
- [ ] Upgrade do corpo da câmera
- [ ] Monitor calibrado
- [ ] Setup estúdio completo

## Como financiar

- Reservar % dos trabalhos fotográficos para reinvestimento
- Presets vendidos → fundo de equipamento
- Comprar usado em bom estado (30-50% mais barato)
- Nunca endividar para equipamento
