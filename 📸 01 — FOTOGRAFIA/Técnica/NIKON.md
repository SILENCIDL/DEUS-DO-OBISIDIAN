## Sistema Nikon — entendendo as opções

### DSLR (montura F) — sistema atual
- Compatível com décadas de lentes Nikon
- Câmeras: D3500, D5600, D7500, D500, D850

### Mirrorless (montura Z) — futuro
- Nova geração (a partir de 2018)
- Câmeras: Z30, Z5II, Z6III, Z8
- Compatível com lentes F via adaptador FTZ

## Configurações base

### Fotografia de retrato
| Config. | Valor sugerido |
|---------|---------------|
| Modo | Av (prioridade abertura) |
| Abertura | f/1.8 – f/2.8 |
| ISO | 100-400 (externo) / 800-3200 (interno) |
| Velocidade | Mínimo 1/100s |
| Perfil de cor | Flat / Neutro |

### Fotografia de rua
| Config. | Valor sugerido |
|---------|---------------|
| Modo | P ou M |
| ISO | Auto (limite 3200) |
| Velocidade | 1/250s ou mais |
| Abertura | f/5.6-8 |

---

## Manutenção

- Sensor: limpar a cada 3-6 meses
- Lente: flanela + líquido próprio
- Bateria: não deixar zerar completamente
- Proteção chuva: capa impermeável (R$ 20-50)
