# Lightroom

> O Lightroom é onde a fotografia se transforma em arte. A câmera captura, o Lightroom revela.

---

## O que é o Lightroom

Adobe Lightroom é o software de edição e organização de fotos mais usado no mundo profissional:

| Versão | Diferença | Uso ideal |
|--------|----------|-----------|
| Lightroom Classic | Desktop, catálogo local | Profissional, volume alto |
| Lightroom (nuvem) | Multiplataforma, nuvem | Mobile + desktop integrados |

---

## Workflow de edição (passo a passo)

```
1. Importar → organizar por data/cliente/projeto
2. Selecionar (rejeitar, marcar com estrela, colorir)
3. Correções básicas: exposição, branco, preto, sombra, realce
4. Perfil de cor + balanço de branco
5. Curva de tons (contraste + cor)
6. Saturação / Vibração (HSL)
7. Detalhe: nitidez + redução de ruído
8. Correção de lente
9. Preset próprio ou importado
10. Exportar: formato, tamanho, perfil de cor
```

## Presets: criar e vender

### Como criar um preset de qualidade
1. Editar uma foto até ficar exatamente como você quer
2. Ir em Desenvolver → Painel Esquerdo → "+" nos Predefinidos
3. Nomear e escolher quais ajustes incluir
4. Exportar como `.xmp` para compartilhar

### O que torna um preset vendável
- Resultado consistente em diferentes condições de luz
- Identidade visual reconhecível (o "estilo Vinicius Rafael")
- Funciona bem em pele, natureza e moda
- Acompanha tutorial de como ajustar
