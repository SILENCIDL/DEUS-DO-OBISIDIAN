# CPU (Computador / Hardware)

> Entender o que está por baixo do software é entender por que o Lightroom trava ou por que o vídeo renderiza devagar.

---

## Por que estudar CPU

Para o trabalho de fotógrafo e criador de conteúdo, a CPU importa diretamente para:
- Velocidade no Lightroom (edição de fotos RAW)
- Render de vídeo (Premiere, DaVinci)
- Exportação em lote de fotos
- Gaming / multitarefa

---

## Componentes essenciais (o básico)

| Componente | Função | Importância para criação |
|-----------|--------|--------------------------|
| CPU (processador) | Cérebro do computador | Alta — determina velocidade de edição |
| RAM | Memória de trabalho | Alta — Lightroom precisa de 16GB+ |
| GPU (placa de vídeo) | Processamento gráfico | Média-alta — aceleração de GPU no Premiere/Lightroom |
| SSD/HD | Armazenamento | Alta — SSD = Lightroom muito mais rápido |
| Monitor | Visualização | Alta — calibração de cor é essencial |

---

## Configuração mínima para fotógrafo/editor

| Componente | Mínimo | Ideal |
|-----------|--------|-------|
| CPU | Intel i5 / Ryzen 5 | Intel i7 / Ryzen 7 |
| RAM | 16GB | 32GB |
| Armazenamento OS | SSD 256GB | SSD 512GB |
| Armazenamento fotos | HD 2TB | SSD 2TB |
| GPU | Dedicada 4GB | 6-8GB+ |
| Monitor | Full HD | 4K calibrado (BenQ SW, etc.) |
