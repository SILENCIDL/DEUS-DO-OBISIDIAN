# Como Me Organizo

> Fotógrafo desorganizado perde tempo, perde arquivo e perde cliente. Organização é parte do trabalho profissional.

---

## Sistema de organização de arquivos

### Estrutura de pastas

```
📁 FOTOGRAFIAS
  ├── 📁 2025
  │    ├── 📁 2025-01 - Cliente Nome
  │    ├── 📁 2025-02 - Projeto Olhar
  │    └── 📁 2025-03 - VRGS Produto
  ├── 📁 2026
  │    └── 📁 2026-03 - [trabalho]
  └── 📁 PORTFOLIO
       ├── 📁 Retrato
       ├── 📁 Produto
       └── 📁 Street
```

### Nomenclatura de arquivo
- `YYYY-MM-DD_Cliente_NomeDoProjeto_001.jpg`
- Exemplo: `2026-03-13_VRGS_CamisetaPreto_001.jpg`

## Workflow completo por trabalho

| Etapa | Ferramenta | Tempo |
|-------|-----------|-------|
| Briefing | Papel / WhatsApp | Antes |
| Importar fotos | Lightroom | 15-30min |
| Seleção (rejeitar / marcar) | Lightroom | 30-60min |
| Edição (lote) | Lightroom | 1-3h |
| Exportar | Lightroom | 15min |
| Entregar | WeTransfer / Drive | 5-10min |
| Arquivar | HD externo | 10min |

---

## Organização do Lightroom

| Coleção | O que vai lá |
|---------|-------------|
| ⭐ Best of [ano] | As melhores fotos do ano |
| 📦 Trabalhos | Por cliente, dentro de pasta por mês |
| 🎨 Projetos pessoais | Projeto Olhar, Cinematic, etc. |
| 🛍️ VRGS | Produto, lookbook, acessórios |
| 🎬 Presets demo | Fotos de demonstração de presets |

## Backup (regra 3-2-1)

| Cópia | Onde | Frequência |
|-------|------|-----------|
| Original | HD do computador | Sempre |
| Backup 1 | HD externo local | Semanal |
| Backup 2 | Nuvem (Google Drive) | Mensal |

> **Regra**: se só tem em um lugar, não tem backup.
