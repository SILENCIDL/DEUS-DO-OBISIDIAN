## Contexto

---

## Setup

1. Instalar Node.js
2. `npm install -g @anthropic-ai/claude-code`
3. Clonar repo localmente
4. Rodar `claude` dentro da pasta do projeto

**Autenticação:** conta Anthropic existente (mesmo login do claude.ai)
**Repos privados:** Personal Access Token do GitHub
