# Design VRGS

> Design não é só logo bonito. É a experiência visual que faz o cliente reconhecer a marca antes de ler o nome.

---

## Identidade visual VRGS

### Paleta de cores oficial
| Cor | Hex | Uso |
|-----|-----|-----|
| Preto | #0A0A0A | Principal, logo, texto |
| Branco off | #F5F5F0 | Fundo, contraste |
| Verde VRGS | #508050 | Destaque, acento |
| Areia | #C8B89A | Secundário, elegância |
| Chumbo | #3A3A3A | Variação do preto |

### Tipografia
| Uso | Família | Estilo |
|-----|---------|--------|
| Logo / headline | Sans-serif geométrica | Bold, uppercase |
| Corpo / legenda | Sans-serif clean | Regular |
| Destaque especial | Script / display | Moderado |

### Logo
- Versão principal: horizontal (texto VRGS + ícone)
- Versão compacta: monograma "V" ou "VRGS" só texto
- Uso em branco sobre fundo escuro / preto sobre fundo claro
- Nunca distorcer, trocar cor ou adicionar sombra

## Aplicações de design

### Posts Instagram
- **Proporção**: 1:1 (feed) ou 4:5 (retrato)
- **Hierarquia**: título > subtítulo > texto de apoio
- **Espaço em branco**: não encher o quadro
- **Consistência**: usar os mesmos elementos visuais

### Stories
- **Proporção**: 9:16
- **Zona segura**: manter conteúdo central (superior e inferior são cortados)
- **CTA visual**: seta, círculo, dedo apontando

### Templates Canva recomendados
- Post produto com fundo limpo
- Carrossel informativo com cores da marca
- Capa de destaques Instagram (ícones minimalistas)
- Flyer de lançamento de coleção

## Design de estampas para roupas

### Conceito VRGS
- **V**irtudes **R**espeito **G**entileza **S**aúde — estampas podem referências esses valores
- Minimalista: menos é mais
- Tipográfico: palavras como elemento gráfico principal
- Simbólico: ícones com significado (não aleatório)

### Softwares de criação
| Software | Uso | Nível |
|---------|-----|-------|
| Canva | Posts, templates, flyers | Iniciante |
| Adobe Illustrator | Vetores, logos, estampas | Intermediário |
| Photoshop | Edição de fotos produto, mockup | Intermediário |
| Procreate (iPad) | Ilustração, desenho à mão | Criativo |

---

## Processo de criação de nova estampa

```
1. Conceito / ideia (o que a estampa comunica?)
2. Referências visuais (Pinterest, Behance)
3. Rascunho / sketch
4. Criação digital (AI, Canva, Illustrator)
5. Mockup na camiseta / peça
6. Feedback (pede opinião antes de produzir)
7. Envio para estamparia / bordado
```
