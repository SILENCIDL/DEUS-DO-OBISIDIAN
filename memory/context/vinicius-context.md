## Red Flags & Course Corrections

### If Photography Feels Like Drudgery
→ Pivot: Try different niche (corporate → product? esporte → corporate?)  
→ Pause: Maybe it's client work (not creative work) that's draining?  
→ Explore: What if it's just business growth pain (normal for year 1)?  

### If Development Skills Stagnate
→ Pick a project that excites you (horta, 3D showcase, not just "improve coding")  
→ Join community (Reddit, Discord, GitHub) for accountability + learning  
→ Course? Book? Tutorial? Find what works (everyone learns differently)  

### If Languages Stop Progressing
→ Switch method (Anki boring? Try immersion + tutoring only)  
→ Find intrinsic motivation (Why this language? Is it still why?)  
→ Pause one language, focus one (spreading thin = progress stops)  

### If Casal Feels Out of Sync
→ Money date now (maybe financial stress = relationship tension)  
→ Conversation: "Are we still on the same page?" (open, non-defensive)  
→ Consider couples therapy (earlier = easier, not failure)  

### If You're Burning Out
→ Stop. Literally. Cancel meetings, simplify goals, rest.  
→ Review: Which projects are non-negotiable? (probably fewer than you think)  
→ Talk to casal: "I need help. I'm stretched."
