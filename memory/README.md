## ✏️ Mantendo a Memória Atualizada

### Quando Algo Muda
1. **Novo projeto?** → Cria arquivo em memory/projects/{name}.md
2. **Nova pessoa importante?** → Adiciona em memory/people/{name}.md
3. **Novo termo/acronimo?** → Adiciona em memory/glossary.md
4. **Mudou de mente sobre algo?** → Atualiza CLAUDE.md + detalhe em memory/

### Cadência de Atualização
- **CLAUDE.md:** Revisar mensal (remove estale, adiciona frequent)
- **memory/glossary.md:** Adiciona contínuo, revisão trimestral
- **memory/people/, projects/, context/:** Update as needed, review trimestral

### Exemplo de Update
```markdown
Mudança: Decidi focar no Portfolio web (Astro)
1. CLAUDE.md → Portfolio status = "Building MVP (Astro chosen)"
2. memory/projects/portfolio.md → Update decision section (Astro final)
3. memory/context/vinicius-context.md → Update Q2 goal
4. CLAUDE.md → Bump Portfolio to top project priority
```

## ⚠️ Important Notes

### This Memory Is Living
- It changes as you learn, grow, change mind
- Not a prison ("oh, I said X in CLAUDE.md so I must do it")
- A mirror ("this is what I said I care about, does it still feel true?")

### Update Signals
When to update memory:
- ✅ You change your mind about something
- ✅ A project completed (celebrate, archive, move on)
- ✅ A new priority emerged
- ✅ You learned something new about yourself
- ✅ Casal goals shifted

When NOT to update:
- ❌ Caught in perfectionism (memory is good enough)
- ❌ Overthinking every detail
- ❌ Treating it like a time-sink (it should save time)

## 🎓 Memory Best Practices

### ✅ Do This
- Keep CLAUDE.md under 100 lines (forces prioritization)
- Use glossary.md as your reference dictionary
- Update quarterly (not constantly)
- Use memory to inform decisions (not dictate them)
- Share relevant parts with casal (transparency)

### ❌ Don't Do This
- Obsess over perfect formatting (utility > aesthetics)
- Update every single day (wasteful)
- Treat memory as final source of truth (think for yourself)
- Keep secrets from casal here (transparency = partnership)
- Ignore signals that memory is outdated (update it)
