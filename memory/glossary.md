## Fotografia (Photography)

| Term | Meaning | Context |
|------|---------|---------|
| **FTP** | Fotografia | Work shorthand |
| **Esporte** | Sports photography | Primary niche (ação, panning, ISO push) |
| **Produto** | Product photography | Secondary niche (lighting, consistency) |
| **Vídeo** | Videography | Cinema work, LOG grading |
| **Retrato** | Portrait photography | People work, lighting, direction |
| **Pack Filmic** | Color grading LUT system | Signature look for Mantiqueira region |
| **LOG** | Nikon N-LOG | Cinema color profile (flat, wide latitude) |
| **LUT** | Look-Up Table | Color grading preset (starting point) |
| **Burst** | Continuous shooting mode | For capturing peak action moments |
| **Panning** | Tracking moving subject | Technique to freeze movement while blurring background |
| **Shutter Speed** | Light exposure time | 1/1000s+ for sports, slow for motion blur |
| **MTF** | Modulation Transfer Function | Lens resolution + contrast charts |
| **Full Frame** | Sensor size (36x24mm) | Z6 II, Z7 II (vs APS-C crop) |
| **APS-C** | Smaller sensor size | Crop factor ~1.5x, less expensive lenses |
| **Tripod** | Stability equipment | Essential for video, long exposures |
| **ND Filter** | Neutral Density | Reduces light → slower shutter = motion blur |
| **Polarizador** | Polarizing filter | Reduces reflections, intensifies colors |
| **RAW+JPG** | File formats | RAW for editing, JPG for backup/quick share |
| **Backup Triplo** | Triple redundancy | Always 3 copies of important photos |
| **Lightroom** | Adobe photo editor | Batch processing, color correction |
| **Photoshop** | Adobe advanced editor | Retouching, compositing |
| **DxO PhotoLab** | Advanced color science | Denoise IA, better shadows |
| **White Balance** | Color temperature adjustment | Nikon SnapBridge, post-edit |
| **Grain** | Film texture | Natural (light variation) vs digital (ugly) |
| **Briefs** | Client requirements | Moodboard, deliverables, expectations |
| **EXIF** | Photo metadata | Camera settings, lens, date-time |
| **Editais** | Grant/competition calls | Brazilian art funding opportunities |

## Desenvolvimento (Development)

| Term | Meaning | Context |
|------|---------|---------|
| **Dev** | Desenvolvimento | Work shorthand |
