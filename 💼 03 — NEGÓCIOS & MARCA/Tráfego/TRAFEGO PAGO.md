# Tráfego Pago

> Tráfego pago = você acelera o que já funciona. Nunca pague para testar algo que não provou orgânico primeiro.

---

## Princípio fundamental

Antes de investir em tráfego pago:
1. ✅ Produto validado (pessoas compram sem anúncio?)
2. ✅ Página de destino funcionando (copy clara, CTA visível)
3. ✅ Pixel instalado e coletando dados
4. ✅ Conhecer o CAC máximo que você pode pagar

---

## Meta Ads (Facebook + Instagram)

### Estrutura de campanha
```
Campanha (objetivo)
  └── Conjunto de Anúncios (público + orçamento)
        └── Anúncio (criativo + copy)
```

### Objetivos por fase do negócio
| Objetivo | Quando usar |
|----------|-------------|
| Alcance | Branding inicial, novidade |
| Engajamento | Crescer página / post viral |
| Tráfego | Levar para link/bio/loja |
| Conversão | Vender produto digital ou VRGS |
| Geração de leads | Capturar contatos para lista |

### Públicos recomendados
- **Frio**: Interesses (fotografia, moda masculina, Lightroom, etc.)
- **Morno**: Seguidores Instagram + visitantes da página
- **Quente**: Lookalike de compradores (1-3% do Brasil)
- **Retargeting**: Quem interagiu nos últimos 30-90 dias

---

## Orçamento inteligente

### Regra dos 3 níveis
| Fase | Orçamento diário | Objetivo |
|------|-----------------|----------|
| Teste | R$ 10-20 | Descobrir o que funciona |
| Escala | R$ 50-100 | Multiplicar o que funcionou |
| Dominância | R$ 200+ | Saturar o mercado-alvo |

### Distribuição por produto
| Produto | % do orçamento |
|---------|---------------|
| VRGS (moda) | 40% |
| Fotografia (serviços) | 30% |
| Produtos digitais (presets/cursos) | 30% |

---

## Métricas essenciais

| Métrica | Sigla | Meta |
|---------|-------|------|
| Custo por clique | CPC | < R$ 1,50 |
| Taxa de clique | CTR | > 1,5% |
| Custo por aquisição | CPA | < 30% do ticket |
| Retorno sobre gasto | ROAS | > 3x |
| Frequência | - | < 3 (evitar fadiga) |

---

## Processo de teste de criativos

```
Semana 1: 3 criativos diferentes → mesmo público
Semana 2: Identificar vencedor (menor CPA)
Semana 3: Escalar vencedor + testar variações dele
Semana 4: Desligar perdedores, manter top 2
```

---

## Tipos de anúncio por produto

### Para VRGS (roupas)
- Vídeo usando a peça (lifestyle, não catálogo)
- Carrossel de looks completos
- Story "swipe up" para compra direta

### Para Fotografia (serviços)
- Antes/depois de edição
- Depoimento de cliente + foto
- "Vagas limitadas para [mês]"

### Para Produtos Digitais
- Transformação: "antes de usar o preset X / depois"
- Resultado de aluno do curso
- VSL (vídeo de vendas curto, 2-3 min)

---

## Pixel e rastreamento

- Instalar Pixel do Meta no site/loja
- Configurar eventos: ViewContent, AddToCart, Purchase
- Usar UTM nos links para rastrear no Google Analytics
- Testar com Meta Pixel Helper (extensão Chrome)

---

## Erros para evitar

- ❌ Mexer no anúncio antes de 3-4 dias de dados
- ❌ Orçamento muito baixo (< R$ 10/dia por conjunto)
- ❌ Público muito amplo sem segmentação
- ❌ Usar só foto estática sem testar vídeo
- ❌ Não ter página de destino dedicada
