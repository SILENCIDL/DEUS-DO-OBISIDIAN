# Anúncios

> Um bom anúncio não parece anúncio. Parece conteúdo que alguém quis mostrar para você.

---

## Visão geral

Os anúncios são o motor de aceleração do negócio. Funcionam em conjunto com:
- [[TRAFEGO PAGO]] — estratégia e configuração de campanhas
- [[CRIATIVOS (ANUNCIOS)]] — o visual e o texto do anúncio
- [[PLANEJAMENTO DE ANUNCIOS (CRIATIVOS)]] — calendário e briefing
- [[LINGUAGEM DO MERCADO]] — como falar com o público certo

## Plataformas e formatos

### Meta Ads (Instagram + Facebook)
| Formato | Melhor para | Dica |
|---------|-------------|------|
| Reels (vídeo) | Topo de funil, alcance | Hook nos 3 primeiros segundos |
| Story vertical | Meio/fundo de funil | CTA direto: "deslize" |
| Carrossel | Educar + converter | 1º card = gancho, último = CTA |
| Feed foto | Branding, produto | Alta qualidade visual obrigatória |

### Google Ads (futuro)
- Search: quando tiver loja/site com volume de busca
- Display: retargeting visual após visita ao site

## O que faz um anúncio funcionar

### Fórmula básica
```
[Gancho] → [Problema/Desejo] → [Solução] → [CTA]
```

### Exemplos por produto

**VRGS (moda):**
> "Essa peça acabou 3x mais rápido do que eu esperava..."
> → Mostra a peça sendo usada → "Link na bio / compre agora"

**Fotografia (serviços):**
> "Antes x Depois: o que acontece quando você investe em fotografia profissional"
> → Slide comparativo → "Me chama no DM para orçamento"

**Preset (produto digital):**
> "Esse é o preset que uso em TODOS os meus trabalhos pagos"
> → Demonstração rápida no Lightroom → "Link na bio para baixar"

## Ciclo de vida de um anúncio

```
1. Briefing → 2. Criativo → 3. Revisão → 4. Subir no Ads Manager
→ 5. Monitorar 3 dias → 6. Otimizar / escalar / pausar
→ 7. Criar nova variação antes de morrer (frequência > 3)
```

---

## Checklist antes de subir um anúncio

- [ ] Criativo em alta resolução / vídeo sem pixelização
- [ ] Copy sem erro ortográfico
- [ ] Link de destino funcionando
- [ ] Pixel ativo na página de destino
- [ ] Público definido (frio, morno ou quente)
- [ ] Orçamento diário definido
- [ ] Data de início e fim (se for campanha sazonal)
