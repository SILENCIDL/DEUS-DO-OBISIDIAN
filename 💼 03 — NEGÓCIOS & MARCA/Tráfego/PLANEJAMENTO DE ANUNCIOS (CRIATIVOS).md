# Planejamento de Anúncios (Criativos)

> Improvisar anúncio é queimar dinheiro. Planejar com antecedência = mais qualidade, menor custo, melhor resultado.

---

## Por que planejar com antecedência

- Criativos com mais tempo de produção = mais qualidade
- Evita publicar algo errado com pressa
- Permite testar antes de lançar campanhas grandes
- Facilita alinhamento entre produto, copy e visual

---

## Briefing de criativo

Antes de produzir qualquer anúncio, responder:

```
Produto:
Público-alvo:
Objetivo (clique / venda / lead):
Mensagem principal (em 1 frase):
Gancho (o que para o scroll):
Call to action (o que o usuário deve fazer):
Formato (foto / vídeo / carrossel):
Onde vai ser veiculado (feed / story / reels):
Orçamento previsto:
Data de início:
```

---

## Fluxo de produção

```
Briefing (D-7)
   ↓
Produção do criativo (D-5)
   ↓
Revisão: visual + copy (D-3)
   ↓
Subir no Ads Manager em modo rascunho (D-2)
   ↓
Ativar / agendar (D-1 ou D-0)
   ↓
Monitorar primeiras 48h (métricas iniciais)
   ↓
Otimizar: pausar ou escalar
```

---

## Checklist de lançamento

### Criativo
- [ ] Alta resolução (foto) ou sem pixelização (vídeo)
- [ ] Gancho nos primeiros 3 segundos (vídeo)
- [ ] Legenda/closed caption ativada
- [ ] Formato correto para o placement

### Copy
- [ ] Headline chamativa (sem clichê)
- [ ] Benefício claro (não só feature)
- [ ] CTA explícito ("clique no link", "me chame no DM")
- [ ] Sem erro de ortografia

### Técnico
- [ ] Link de destino testado
- [ ] Pixel ativo e disparando
- [ ] Orçamento diário definido
- [ ] Público correto (não muito amplo, não muito restrito)
