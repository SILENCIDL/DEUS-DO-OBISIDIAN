# ✍️ Copy — A arte de escrever para vender

Categoria: [[Ideas Extraordinárias - Monetização e Escala]]

> Copy não é enganação. É conectar o que você tem com o que a pessoa precisa.

---

## O que é copywriting

Copy é a escrita persuasiva que **move pessoas à ação** — comprar, seguir, clicar, responder. É a voz do seu negócio em texto.

---

## 🏗️ Estruturas de copy que funcionam

### AIDA
| Etapa | O que fazer | Exemplo |
|-------|-------------|---------|
| **Atenção** | Parar o scroll | "Você está perdendo dinheiro sem saber" |
| **Interesse** | Gerar curiosidade | "Fotógrafos que fazem R$5k/mês fazem isso diferente" |
| **Desejo** | Mostrar transformação | "Imagine acordar com pedidos de orçamento na caixa" |
| **Ação** | CTA direto | "Manda 'foto' aqui no DM agora" |

### PAS
- **Problema**: Nomear a dor real do cliente
- **Agitação**: Mostrar as consequências de não resolver
- **Solução**: Apresentar o que você oferece

### FAB
- **Feature** (característica): O que é
- **Advantage** (vantagem): O que faz
- **Benefit** (benefício): O que muda na vida do cliente

## 📝 Templates de copy

### Caption de post
```
[HOOK — primeira linha para parar o scroll]
[Contexto em 2-3 linhas]
[Desenvolvimento do assunto]
[CTA no final]
#hashtags
```

### DM de primeiro contato
```
Olá [Nome]! Vi seu perfil e percebi [observação específica].
Trabalho com [serviço] e já ajudei [resultado concreto].
Teria interesse em conversar sobre [benefício]?
```

### Bio do Instagram
```
[Quem sou] | [O que faço] | [Resultado que entrego]
[Prova social ou diferencial]
👇 [CTA com link]
```

## 💡 Gatilhos mentais essenciais

| Gatilho | Como usar |
|---------|-----------|
| **Prova social** | "Mais de X clientes atendidos" |
| **Escassez** | "Últimas vagas do mês" |
| **Urgência** | "Só até domingo" |
| **Autoridade** | "Especialista em fotografia há X anos" |
| **Reciprocidade** | Dar valor antes de pedir |
| **Especificidade** | Números concretos vs genéricos |
| **Transformação** | Antes x Depois |
